📐 系統架構與解決方案說明

1. 商業痛點與設計初衷
傳統農牧與第一線製造現場作業人員雙手忙碌、環境潮濕，無法低頭打字填表，導致現場異常漏報、交接資訊斷層、文書整理耗時。本系統以「免動手全語音輸入 ＋ 單一事實來源（SSOT）關聯式資料庫」為核心，將口語指令直接轉化為可追蹤的排程狀態機與管理層簡報。

2. 技術棧（Tech Stack）
HTML5 / Vanilla JS Web Speech API MediaPipe Face Landmarker SVG 動態平面圖渲染 Google Apps Script REST API Relational Database Schema

3. 核心工程亮點

  • 行動端瀏覽器語音狀態機：針對 iOS Safari 設計單句無縫續接與音量頻譜回饋，支援口語關鍵詞即時中斷與贅字過濾正規化。
  • 防誤觸人機介面（HMI）：針對現場戴手套操作，設計「暫存勾選可還原 ＋ 滑動到底二次確認」機制，杜絕誤寫資料庫。
  • 輕量化生物辨識權限控管：前端透過 MediaPipe 提取五角度正規化幾何向量比對，區分「操作人員（全功能）」與「訪客（唯讀看板）」。
  • 資料脫敏與安全隔離：本公開展示版已抽離正式環境 API 端點與商業數據，改由內建模擬引擎驅動完整互動流程。
